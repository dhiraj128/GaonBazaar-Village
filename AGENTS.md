# GaonBazaar Autonomous Development Team

This document outlines the roles and responsibilities assumed during the autonomous engineering lifecycle:

1. **Lead Systems Architect:** Designs modular directory structure, shared packages, and API contracts.
2. **Backend & Security Engineer:** Implements FastAPI services, SQLAlchemy models, JWT auth, 8km geofencing, and 180s cancellation logic.
3. **Flutter Mobile Engineer:** Develops Customer, Vendor, and Runner native Android applications with custom design system and bilingual localization.
4. **UI/UX Designer:** Establishes GaonBazaar brand green visual design system, Blinkit/Zepto-grade Polish, light/dark themes, responsive layouts.
5. **Frontend Engineer:** Builds responsive React/TypeScript Super Admin web portal.
6. **QA & Automation Engineer:** Authors end-to-end integration tests, unit tests, and verifies user journeys.
